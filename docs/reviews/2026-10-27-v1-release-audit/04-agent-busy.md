# Agent busy

- verdict: PASS
- blockers: 0
- high: 0
- scope: busy signals, session and transcript mtimes, CPU-busy, OpenCode paths, the four-tool multi-select, the empty-selection clamp, the I3 terminal-session preference, settle-grace clamps, and never-busy versus busy-seen-this-arm. The disengage sleep call is a WatchEngine handoff. Question forwarding is out of scope.

## Product promise

Keep awake in Agents mode stays on while selected tools show local busy signals, then waits out the idle grace and turns off. Busy signals come only from Cursor, Claude Code, Codex, and OpenCode. Default is all four on. The saved set is never empty. Nested `/subagents/*.jsonl` counts only for a selected parent, and only while the file mtime is inside the 45s freshness window. That path is not the terminal-session toggle. Terminal session files count only when “Count terminal sessions as busy” is on, and only for tools already walked. That preference defaults off. OpenCode is process plus session files. Claude and Codex may also use CPU. A quiet gap shorter than the grace does not look finished. An arm that never saw a busy signal does not post and does not disarm. This is local process, CPU, and file mtime evidence. It is not think-detection.

## Handoffs

- WE: `agentsSettled` is emitted only after `.settled`, which already requires busy-seen and a full continuous grace (`WatchEngine.swift:221-227`, `AgentSettleTracker.swift:40-44`). `disengage` may then append `.requestSleep` when `lidClosed` was true (`WatchEngine.swift:365-366`, `TelegramInboundDisarm.shouldRequestSleep` at `Sources/AgrypnosCore/Notif/TelegramInboundPolish.swift:51-55`). That sleep line was not re-audited. Whether the flag passed there is the stable confirm is WatchEngine’s.
- Q: while a question wait is `.hold` or `.deferTimeout`, the tick records busy or interrupts observations and does not take the settle branch (`WatchEngine.swift:215-220`). Question forwarding was not reviewed.
- Probe unknown: a result whose walk took longer than 15s, or whose completion is 5s or older, or whose walk did not finish, is not idle (`AgentProbeObservation.swift:18-24`, `AgentSnapshotCache.swift:5`, `SessionWalkBudget.swift:5`, `AgentProbeService.swift:169`). The runtime then restarts the quiet wait (`WatchRuntime+Poll.swift:136-138`). That keeps a never-busy arm from disarming. It can also delay a real settle. See Unproven.

## Needs a Mac

- Arm Agents with one tool selected. Confirm the other three do not hold the watch. Turn the last tool off and confirm the switch snaps back on.
- I3 off: a live Cursor `terminals` file updating, with the agent transcript quiet, must not count as busy. Turn I3 on and confirm that same file can.
- OpenCode CLI: a fresh session file plus the process holds the watch. High CPU with a stale session file must not. Confirm the desktop app’s real `ps` args. The `.app` executable is ignored; `opencode-cli` counts.
- Claude and Codex CLI at or above 5% CPU can hold the watch with a stale session file. Cursor CPU alone must not.
- See a busy signal, then a quiet gap shorter than the grace: Keep awake stays on. After the full grace, it turns off. With Notif on, one idle-after-wait message. An arm that never goes busy stays on and does not post.

## Unproven

- This pass did not run `swift test` or `xcodebuild`. The results above are from the source and the existing tests, read line by line, not from a run tonight.
- Live `ps` names, this Mac’s OpenCode and Cursor trees, and a physical quiet wait were not observed.
- A quiet walk that hits the 4000-visit cap, or a probe that takes longer than 15s, is unknown rather than idle (`AgentProbeService.swift:169`, `AgentProbeObservation.swift:21-24`). Whether this Mac’s session trees do that was not measured. If they do, Agents mode will not reach `agentsSettled` until a later probe returns a complete idle.
- No install prefs were opened. A hand-edited `sessionFreshness` from 15 through 120 would stick (`UserPreferences.swift:145-151`). The app’s own default is 45, and nothing in the popover writes another value.
